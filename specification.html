作品規格書

版本 1.0｜2026-10-13

一、想法與使用對象

學生讀書時容易分心，也常不知道從哪一科開始。以任務清單結合專注計時器，把「想讀書」拆成可以完成的小步驟。對象為需要安排自習的學生。

二、使用流程

輸入任務與優先順序 → 加入清單 → 選擇本輪任務 → 開始專注 → 計時結束 → 自行勾選已完成 → 休息或開始下一輪。

三、功能與驗收

  • 新增任務：名稱最多 80 字，空白不得加入；支援一般／優先。
  • 任務管理：可勾選完成、取消完成、刪除與篩選；優先任務排在前面。
  • 計時器：專注 25 分鐘、休息 5 分鐘；可開始、暫停、繼續與重設。切換模式會重設本輪。
  • 統計：完成專注輪才累加今日輪數與分鐘；休息、暫停與中途重設不計入。
  • 持久化：任務與每日統計使用 localStorage；重整保留資料，計時器重設。
  • 匯出：下載 JSON，包含任務與各日專注紀錄；不提供匯入功能。
  • 介面：手機單欄、桌面雙欄；支援鍵盤、焦點標記與操作提示。

四、技術與範圍

單一 index.html，內嵌 CSS、JavaScript；不使用外部套件、API、後端或真實 AI 服務。AI 用於協助規劃及程式實作。以 GitHub Pages 發布靜態頁面。資料僅限同一瀏覽器與網站來源，不跨裝置同步。背景頁籤可能延後通知，回到頁面時校正時間。

五、設計與改善方向

採用奶油白與深綠色，讓任務與計時容易辨識。加入輸入檢查、安全文字呈現、儲存失敗提示、跨日統計與鍵盤操作。實際測試與修正另附紀錄文件。

六、資料欄位與行為細節

任務欄位：識別碼、名稱、優先順序、完成狀態。每日紀錄以本機日期為索引，記錄專注輪數與分鐘。跨日完成的專注輪計入完成當日。任務沒有日期欄位，待辦清單會跨日保留。

專注任務是本輪的注意力提示，不會自動完成，也不會在匯出紀錄中建立任務與專注輪數的關聯。使用者自行勾選完成。暫停期間鎖定本輪選擇，重新計時後可改選。

七、驗收表

項目驗收條件
輸入與排序空白不新增；優先任務排在一般任務前；輸入的 HTML 文字不被執行。
任務操作完成、取消、刪除、三種篩選與清除已完成均更新清單與統計。
計時專注為 25:00，休息為 05:00；暫停不扣時間，繼續可接續。
每日紀錄專注結束只計一次；休息與中途重設不累加；跨日顯示新的一日。
儲存重整可恢復任務及統計，計時重設；儲存不可用時有提示。
匯出與規格JSON 包含任務與每日紀錄；規格視窗可開啟及關閉。
手機與公開連結手機單欄且沒有水平溢出；GitHub Pages 可公開開啟並操作。

八、課堂與作業對應

依「05AI怎麼記得前面說過什麼？」PDF 第 68–85 頁的作業段落，先釐清用途與規格、製作單一 HTML，再透過 GitHub Pages 公開。課堂前段的 RNN 與 Attention 是教材背景，本作品依自由選題要求採讀書工具，不要求實作模型。

依補充上傳指引，index.html 必須放在儲存庫最外層；檔名採英文小寫。發布設定為 main 分支、/ (root)。

九、評分項目對應

  • 規格清楚具體：本文件列出使用對象、流程、功能、資料與驗收條件。
  • 實際互動：任務管理、計時、統計、資料保存及匯出。
  • 規格與作品一致：各項驗收直接對應畫面功能。
  • AI 改善證據：development-log.txt 保存需求確認、檢查及修正紀錄；對話中可查到使用者確認主題。
  • GitHub Pages：以實際發布的網址及瀏覽器檢查結果為準，不以本機檔案代替。

可使用瀏覽器的列印功能保存成 PDF。實際測試結果請參閱 development-log.txt。
